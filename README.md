# FaceIn – Automated Attendance System

FaceIn is an automated attendance management system that uses facial recognition to identify students and record their attendance. It reduces manual effort, minimizes errors, and provides a fast and reliable way to manage attendance.

## ✨ Features

- Face recognition-based attendance
- Automatic student identification
- Attendance recording
- Reduced manual work and errors
- Simple and user-friendly system

## 🛠️ Technologies Used

- Python
- OpenCV
- Face Recognition
- MySQL
- HTML/CSS/JavaScript

## ⚙️ How It Works

1. Register student details and facial data.
2. The system captures the student's face through a camera.
3. Face recognition identifies the student.
4. Attendance is automatically recorded.
5. Attendance records can be viewed and managed.

## 🎯 Purpose

The project aims to make attendance management faster, easier, and more reliable by replacing traditional manual attendance methods with facial recognition technology.
